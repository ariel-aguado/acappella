# Acappella

Acappella es una aplicación web para gestionar himnos y cánticos espirituales usados por la Iglesia de Cristo, diseñada para facilitar la alabanza desde cualquier lugar.

## Setup

Make sure to install dependencies:

```bash
# pnpm
pnpm install
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
# pnpm
pnpm dev
```

## Production

Build the application for production:

```bash
# pnpm
pnpm build
```

Locally preview production build:

```bash
# pnpm
pnpm preview
```
